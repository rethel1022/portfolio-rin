# メール対応・文章整理 ポートフォリオ

## 制作目的

このポートフォリオは、メールでの顧客対応経験を土台に、問い合わせ返信、FAQ、商品説明、メルマガ案など、文章で情報を整理する業務への適性を示すために作成した自主制作サイトです。

バナー案、SNS投稿案、HTML/CSSページはAI/Codex補助を使って作成しており、現時点ではCanva/FigmaやHTML/CSSを単独で実務対応できるスキルとしては打ち出していません。

## 使用技術

- HTML5
- CSS3 / CSS変数
- 最小限のVanilla JavaScript
- レスポンシブ対応
- 外部ライブラリなし

JavaScriptはナビゲーション開閉など必要最小限です。高度な開発力を示す目的ではなく、AI/Codex補助で作成した静的ページを、本人が文面確認・内容整理・表現調整した自主制作サンプルとして掲載しています。

## 使用ツールと前提

- AI/Codex補助: HTML/CSSページ構成、バナー風レイアウト、SNS投稿文案、メルマガ案、FAQ案の作成補助
- 本人が行ったこと: 題材選定、文面確認、違和感のある表現の修正、実際の経歴と矛盾しない表現への調整
- 画像: 著作権リスクを避けた自作SVG、CSS図形、プレースホルダー、AI生成の架空イメージ

実在企業のロゴ、実在商品画像、商標画像、素材サイト写真は使用していません。

## AIの使い方

AI/Codex補助は、制作を丸投げするためではなく、たたき台作成、文章整理、比較、確認項目の洗い出しに使用しました。最終的な表現調整、誤字脱字、実際の経歴と矛盾しない表現への修正は本人が行う前提です。

主な利用範囲:

- 商品説明文の初稿作成
- SNS投稿文案の比較
- バナー文言案の整理
- メルマガ件名案の作成
- FAQの整理
- 誤字脱字・表記ゆれ確認

個人情報や社外秘情報はAIに入力しません。事実情報は必ず自分で確認します。

## 自分で判断・修正した点

- 実際の経験を「メールでの顧客対応」に限定して説明したこと
- 問い合わせ返信、FAQ、商品説明、メルマガ案など、文章整理に近い題材へ寄せたこと
- バナー案やWebページを、単独制作スキルではなくAI/Codex補助の自主制作サンプルとして明記したこと
- 架空案件が実務実績に見えないよう、各ページで自主制作サンプルであることを示したこと
