# EC・Web運用サポート ポートフォリオ

## 制作目的

転職応募前に公開するため、顧客対応・事務経験を活かし、AIとCanva/Figma/HTML/CSS学習を組み合わせて、EC運営・Web更新・SNS投稿・広報補助・営業支援を正確に支えられることを示すポートフォリオです。

Webデザイン作品だけを見せるのではなく、商品情報整理、問い合わせ整理、メール文面作成、公開前チェック、販促資料作成など、実務に近い運用補助を再現しています。

## 使用技術

- HTML5
- CSS3 / CSS変数
- 最小限のVanilla JavaScript
- レスポンシブ対応
- 外部ライブラリなし

JavaScriptはナビゲーション開閉など必要最小限です。高度な開発力を大きく見せる目的ではなく、静的HTML/CSSを中心に、応募先で説明できる範囲で構成しています。

## 使用ツール

- Canva/Figma相当: バナー、SNS投稿案、LP構成案の自主制作想定
- AI: 案出し、文章整理、比較、チェックリスト作成
- HTML/CSS: 静的ページ、表、カード、Before/After、チェックリストの作成

画像は著作権リスクを避け、CSS図形・SVG・プレースホルダーで作成しています。実在企業のロゴ、実在商品画像、商標画像、素材サイト写真は使用していません。

## ページ構成

公開ナビは「トップ」「Case 01」「Case 02」「Case 03」「AI活用」「チェック」「概要1枚」に統一しています。内部確認用資料は提出用の公開ナビ、README、主要CTAからリンクしません。

## AIの使い方

AIは、制作を丸投げするためではなく、案出し、文章整理、比較、チェックリスト作成の補助として使用しました。最終的な構成、表現、誤字脱字、価格・在庫・日付・リンク・表記ゆれの確認は、自分で行う前提です。

主な利用範囲:

- 商品説明文の初稿作成
- SNS投稿案の比較
- メルマガ件名案の作成
- FAQの整理
- チェックリスト作成
- 誤字脱字・表記ゆれ確認

個人情報や社外秘情報はAIに入力しません。事実情報は必ず自分で確認します。

## 自分で判断・修正した点

- 応募先ごとに見るべき制作物を分けたこと
- 商品ページでは、サイズ、素材、納期、ギフト対応、返品条件など購入前不安を減らす項目を追加したこと
- メルマガ、SNS、バナー、LPの文言を、掲載先ごとの長さと目的に合わせて調整したこと
- 公開前チェックリストで、価格、在庫、日付、リンク、画像、スマホ表示を確認項目化したこと
- Case 03を plus closet のファッションEC運用・販促ケースへ差し替えたこと

## ローカルでの見方

静的HTML/CSSサイトのため、ビルドや依存関係のインストールは不要です。

1. `portfolio-rin/index.html` をブラウザで開く
2. トップページの応募先別カードから該当ケースを見る
3. `ai-report.html` と `portfolio-summary.html` でAI補助と本人確認の分担、提出用の概要を見る
4. 必要に応じて `portfolio-summary.html` をPDF化想定の概要として確認する
